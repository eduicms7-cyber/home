# 작업실

프로그램, 관심 분야, 프로젝트별 작업일지를 모아 두는 개인 홈페이지입니다. 별도의 패키지 설치나 빌드 없이 정적 호스팅에 배포할 수 있습니다.

## 로컬에서 보기

`index.html`을 브라우저에서 열면 메인 페이지를 볼 수 있습니다. 프로젝트 작업일지는 각 카드의 **작업일지** 링크에서 열립니다.

## 프로젝트와 작업일지 추가하기

1. `projects.js`의 `window.siteProjects` 배열에 프로젝트 항목을 추가합니다.
2. `id`는 고유하게 정하고, `category`에는 `persona` 또는 `education`을 지정합니다.
3. `url`, `repository`, `description`, `status`, `visual`, `symbol`과 `logs` 기록을 입력합니다.
4. 변경 사항을 저장하면 홈페이지 카드와 프로젝트별 작업일지 페이지에 자동으로 반영됩니다.

기존 프로그램의 상세 작업일지를 따로 관리하고 있다면 `workLogUrl`을 지정해 해당 문서로 연결할 수 있습니다. 새 카테고리를 만들면 `index.html`의 카테고리 필터에도 `data-filter` 버튼을 추가합니다. 메뉴 이름이나 관심 분야 문구는 `index.html`에서 바꿀 수 있습니다.

## 배포

정적 사이트를 지원하는 호스팅 서비스에서 이 폴더를 프로젝트 루트로 지정해 배포합니다. 별도의 빌드 명령은 필요하지 않습니다.
