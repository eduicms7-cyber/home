# 작업실

프로그램, 관심 분야, 함께 나눈 이야기와 프로젝트별 작업일지를 모아 두는 개인 홈페이지입니다. 별도의 패키지 설치나 빌드 없이 정적 호스팅에 배포할 수 있습니다.

## 로컬에서 보기

`index.html`을 브라우저에서 열면 메인 페이지를 볼 수 있습니다. 프로젝트 작업일지는 각 카드의 **작업일지** 링크에서 열립니다.

## 프로젝트와 작업일지 추가하기

1. `projects.js`의 `window.siteProjects` 배열에 프로젝트 항목을 추가합니다.
2. `id`는 고유하게 정하고, `category`에는 `persona` 또는 `education`을 지정합니다.
3. `url`, `repository`, `description`, `status`, `visual`, `symbol`과 `logs` 기록을 입력합니다.
4. 변경 사항을 저장하면 홈페이지 카드와 프로젝트별 작업일지 페이지에 자동으로 반영됩니다.

기존 프로그램의 상세 작업일지를 따로 관리하고 있다면 `workLogUrl`을 지정해 해당 문서로 연결할 수 있습니다. 새 카테고리를 만들면 `index.html`의 카테고리 필터에도 `data-filter` 버튼을 추가합니다. 메뉴 이름이나 관심 분야 문구는 `index.html`에서 바꿀 수 있습니다. 함께 나눈 이야기의 기사 카드는 `index.html`의 `stories-section`에 추가합니다.

## 빠진 작업일지 점검하기

각 프로젝트의 `docs/작업일지.md`를 GitHub에서 읽어, `projects.js`에 아직 없는 날짜를 보여 줍니다. 맥·윈도우 모두 같은 명령입니다.

```
node scripts/sync-logs.mjs
```

Node.js와 GitHub CLI(`gh`) 로그인이 필요합니다. 비공개 저장소도 `gh` 로그인 계정으로 읽습니다. 보여 준 날짜는 `projects.js`의 해당 프로젝트 `logs` 맨 앞에 방문자용 한 줄 요약으로 추가합니다.

## 배포

정적 사이트를 지원하는 호스팅 서비스에서 이 폴더를 프로젝트 루트로 지정해 배포합니다. 별도의 빌드 명령은 필요하지 않습니다.
